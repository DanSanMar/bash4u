### 📌 **Explicación del Script**

1. **Bienvenida y menú principal**:
   - Muestra las opciones disponibles al usuario.
   - Usa `case` para manejar las elecciones del usuario.

2. **Condicionales (`if-elif-else`)**:
   - Verifica si el usuario ingresa un número válido o "salir".
   - Muestra mensajes diferentes según la opción elegida.

3. **Bucles (`for`)**:
   - Itera sobre una lista de frutas y un rango de números (1-5).
   - Muestra cómo usar `{1..5}` para generar rangos.

4. **Bucles (`while`)**:
   - Pide al usuario que ingrese "fin" para terminar el bucle.
   - Muestra el uso de `read` y `break` para controlar el flujo.

5. **Bucles (`until`)**:
   - Crea un archivo temporal y espera hasta que exista.
   - Muestra cómo usar `touch` y `rm` para manejar archivos.

6. **Operadores lógicos (`&&`, `||`, `test`)**:
   - Verifica si un archivo existe y lo procesa.
   - Muestra cómo usar `ls -l` con operadores lógicos.

7. **Estructura del script**:
   - Usa una función `main` para organizar el flujo.
   - Incluye comentarios para explicar cada parte.

---

### 📌 **¿Cómo Usarlo?**

1. Guarda el script en un archivo, por ejemplo: `ejemplos.sh`.
2. Hazlo ejecutable con:
   ```bash
   chmod +x ejemplos.sh
   ```
3. Ejecútalo:
   ```bash
   ./ejemplos.sh
   ```

- Operadores lógicos para controlar el flujo.
